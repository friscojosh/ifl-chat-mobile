# IFL Chat mobile

IFL Chat for iPhone and Android: a fork of the Mattermost mobile app (`ifl/main`, upstream base in `ifl/UPSTREAM`) that connects only to `https://chat.iflgm.com`, signs in with "Sign in with iflgm.com", shows each GM's team chip and gets pushes through IFL's own push proxy. Server: `friscojosh/ifl-chat`. Design and plan: ifl-website `docs/superpowers/specs/2026-11-21-ifl-chat-apps-design.md`, `docs/superpowers/plans/2026-11-21-ifl-chat-apps.md`.

New IFL code: `app/utils/ifl/`, `app/components/ifl/` (inside existing path aliases), `ifl/` (assets, fastlane settings, scripts) and `.github/workflows/ifl-*.yml`. Upstream edits are hooks marked `// IFL:` (`{/* IFL: */}` in JSX), listed below. Nothing generated at build time is committed: CI copies `ifl/assets` to `assets/override` (git-ignored upstream) and `ifl/fastlane.env` to `fastlane/.env.ifl`, and fastlane rewrites identifiers with `COMMIT_CHANGES_TO_GIT=false`.

## What the fork changes

- **Locked server.** `config.json` auto-connects to chat.iflgm.com; `IflLockServer` hides the server switcher where upstream hides it for MDM and on the data-erased screen, makes the server address read-only, and refuses deep links to any other host (`app/utils/ifl/config.ts`). About links go to iflgm.com.
- **Team chips.** After each GM's name in posts and user lists, from `GET /api/v4/ifl/team_badges` (per server, in memory; on first use, app foreground and the `custom_ifl_team_badges_changed` event; a failed fetch keeps what was there): the team abbreviation on its colour (`IflTeamChipStyle: "abbr"`, phones' choice: no NFL logos), or the logo (`"logo"`). Accessible label "<Team name> · <Conference>". `app/utils/ifl/team_badges.ts`, `app/utils/ifl/websocket.ts`, `app/components/ifl/team_chip.tsx`.

## Overrides (no code)

`scripts/generate-assets.js` copies `assets/override/<path>` over `assets/base/<path>` into `dist/assets/` (JSON shallow-merged); a file with no base counterpart is ignored, so every override keeps a base file's path and name.

- `ifl/assets/config.json`: `DefaultServerUrl` `https://chat.iflgm.com` with `AutoSelectServerUrl` (the server screen connects at once), `DefaultServerName` "IFL Chat", auth schemes `iflchatauth://` / `iflchatauthdev://`, website and notice links, review and onboarding off, and three IFL keys read by `app/utils/ifl/config.ts`: `IflLockServer` (no other servers), `IflTeamChips` (team chip after GMs' names) and `IflTeamChipStyle` (`"abbr"`: abbreviation on the team colour; `"logo"`: the team logo).
- `ifl/assets/i18n/en.json`: 18 strings ("Sign in with iflgm.com" on the GitLab button, "IFL Chat" in place of "Mattermost" where members read it, "the league" for "a team", "the commissioner" for "your System Administrator"). `settings.about.copyright` stays Mattermost's.
- `ifl/assets/images/` (the sign-in button image `Icon_Gitlab*.png`, so the button shows the IFL icon and not GitLab's logo; `logo.png`, `icon.png`), `ifl/assets/release/icons/{ios,android}/` and `ifl/assets/release/splash_screen/{ios,android}/`: generated by `ifl/scripts/gen-icons.sh` (ImageMagick 7 and librsvg) from `ifl/assets/src/ifl-chat-icon-1024.png` (the master icon, `friscojosh/ifl-chat` `branding/`) and `ifl/assets/src/notification.svg` (Android status-bar glyph). `src/` has no base counterpart; CI does not copy it. Android splash colours (`values{,-night}/colors.xml`): the icon's slate `#34465F`.
- `ifl/fastlane.env`: identifiers and schemes for fastlane (no secrets), copied to `fastlane/.env.ifl` and used as `--env ifl`.

## Build and release

See "Releases". `ifl-ci.yml` runs types, lint and the IFL tests on every push and pull request, and builds a debug-signed Android release APK with the placeholder `ifl/ci/google-services.json`. Upstream test and build workflows are disabled.

## Upstream releases

1. Before merging a release, compare its `app/constants/supported_server.ts` `FULL_VERSION` with the server fork's Mattermost version; if the app needs a newer server, merge the server first.
2. `git fetch upstream --tags`, `git checkout ifl/main`, `git merge <tag>`; keep every `// IFL:` hook.
3. `rm -rf assets/override && cp -R ifl/assets assets/override && rm -rf assets/override/src && npm ci && npm run tsc && npx jest app/utils/ifl app/components/ifl`.
4. Set `ifl/UPSTREAM`; push; run the release.
